DevTool

A desktop workspace for coding agents, with a companion app for iPhone and iPad.

DevTool for iOS pairs with the DevTool desktop app by scanning a QR code. From your phone you can see which agents are working or waiting, read and continue Claude chats, answer permission requests and questions, and start new chats in existing tasks. Everything between your phone and your desktop is end-to-end encrypted.

Servers

DevTool can also run projects on another Linux or macOS machine, so terminals and agents keep working while your laptop sleeps. Read what the server installer does.

Support

Report a problem or ask a question in the GitHub issue tracker. The source code of the desktop app, the iOS app and the relay is in the same repository.

Privacy

No account, no analytics, no tracking. Read the privacy policy.
